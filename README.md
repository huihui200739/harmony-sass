# ohos_harmony-sass

ohos_harmony-sass 面向 OpenHarmony/HarmonyOS PC 与 2-in-1 设备，提供原生 Sass 编辑与编译工作流。应用保留 ArkTS 双栏编辑器界面，内置官方 Dart Sass 1.101.6 浏览器运行时，通过 ArkWeb 生命周期桥接官方 sass.Compiler 和 sass.AsyncCompiler，不重新实现、修改或删减 Sass 语言编译器。
